# App iPhone "Quét Hàng Hoàn"

Vỏ Capacitor bọc nguyên `mobile_scanner.html`. Thư mục `www/` và dự án Xcode được tạo
tự động trong workflow `.github/workflows/build-ios-app.yml` (không commit vào repo).

File `.ipa` tạo ra **chưa ký**; cài lên iPhone bằng AltStore hoặc Sideloadly bằng Apple ID
(Apple ID miễn phí: app hết hạn sau 7 ngày, cài lại để gia hạn).
